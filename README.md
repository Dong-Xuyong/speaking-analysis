# Speaking Analysis

GitHub Pages archive of YouTube speaking samples scored against the YouTube wiki public-speaking corpus (Vinh Giang OS: Structure / Delivery / Authority / Communication Levels).

**Live:** https://dong-xuyong.github.io/speaking-analysis/

## Local preview

```bash
cd speaking-analysis
python -m http.server 8765
# open http://localhost:8765/
```

## Add a session

1. Fetch transcript: `python youtube-app/transcript.py <youtube-url>`
2. Create `sessions/<slug>/analysis.md`, `meta.json`, `scores.json` (use the `speaking-analysis` Cursor skill)
3. Sync: `python scripts/sync_speaking_analysis.py`

## Data layout

```
sessions/<slug>/
  analysis.md   # coach writeup
  meta.json     # title, date, video_id, url, context, summary, status
  scores.json   # layers, levels, focus_next
data/           # generated by build script — do not hand-edit
```
